# XXII Web Components

PWA client built with vanilla Web Components.

## Run Locally

```bash
npx serve . -p 3000
```

Open http://localhost:3000

## PWA Manifest

The `manifest.json` file defines:

- App identity (name, description, icons)
- Display mode (standalone)
- Theme colors
- Start URL and scope

Connected via `<link rel="manifest" href="/manifest.json">` in `index.html`.
